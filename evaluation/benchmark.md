# Benchmark Protocol

1. Select a fixture or a real repository with permission.
2. Record task prompt and initial commit hash.
3. Run Aether without revealing the expected defects.
4. Score findings against fixture labels.
5. Record false positives, false negatives, severity calibration, time, edits, and test outcomes.
6. Repeat with the same model/runtime/settings for comparisons.
7. Do not treat one benchmark run as proof of general reliability.
