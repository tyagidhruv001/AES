# Incident Debugging
1. Capture impact, expected/actual behavior, sanitized logs and timestamps.
2. Debugging Engineer reproduces safely and tests ranked hypotheses.
3. No production reset, deletion, migration, or config change without approval.
4. Implement minimal root-cause fix if authorized.
5. QA adds/runs regression test.
6. Independent Reviewer checks adjacent failure paths.
7. Report root cause, mitigation, verification, and prevention.
