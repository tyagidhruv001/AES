# Release Readiness
1. DevOps inspects build, CI, runtime config, observability, and rollback.
2. QA verifies acceptance criteria and regression suite.
3. Security reviews release-sensitive changes.
4. Independent Reviewer checks final diff.
5. Confirm migration/backup/rollback and approvals.
6. Do not deploy or change cloud resources without explicit authorization.
7. Produce release decision with evidence and blockers.
