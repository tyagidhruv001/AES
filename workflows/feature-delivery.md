# Feature Delivery
1. Define outcome, non-goals, acceptance criteria, compatibility constraints.
2. Planner inspects impacted modules and creates task/test plan.
3. Architect reviews cross-module/API/data/security design.
4. One Senior Developer implements the approved scope and tests.
5. QA independently executes risk-based checks.
6. Security reviews changes involving auth, personal data, payments, uploads, external input, or infrastructure.
7. Independent Reviewer reviews final diff in fresh context.
8. Fix blocking findings; rerun affected checks; report evidence and residual risk.
